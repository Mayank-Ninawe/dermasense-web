# DermaSense Frontend

This directory contains the Next.js web application for DermaSense.

## Setup & Running

1. Open your terminal in this directory (`cd frontend`).
2. Install dependencies (if you haven't already):
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

The application will be accessible at [http://localhost:3000](http://localhost:3000).

## Tech Stack
- Next.js (App Router)
- React
- Tailwind CSS
- shadcn/ui
